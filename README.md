# MasterBot

Offline-first, gamified mastery app for robotics knowledge across three pillars:
**IT, Mechanical, Electronic**. No login, no server dependency for progress â
this repo is the single source of truth for content and adaptive-learning
rules; the Android app is a renderer + local engine that clones/pulls it.

Full product/architecture spec: [MASTERBOT_SPEC.md](MASTERBOT_SPEC.md).

## Guardrails

- `index.json` is generated by CI (`tools/build_index.py`), never hand-edited.
- Any change to scoring/weighting behavior is a diff to `rules/adaptation_rules.yaml`
  â never hardcoded in app logic.
- This repo is **public** and requires zero authentication to clone/pull.
  Never commit API keys, tokens, or credentials.
- Content flow: edit `notes.md` / `cards.yaml` â push â CI validates against
  `schema/` and rebuilds `index.json` â app picks it up on next pull.
