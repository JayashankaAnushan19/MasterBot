# GPIO & PWM Fundamentals

GPIO pins and PWM generation are the microcontroller's most basic interface
to the physical world — every button read, LED blink, and motor speed
command on a small robot controller goes through one or both.

## GPIO: general purpose input/output

Each GPIO pin can typically be configured as:

- **Digital output**: the microcontroller drives the pin high (logic 1,
  usually the supply voltage) or low (logic 0, ground).
- **Digital input**: the microcontroller reads whether an external signal
  is driving the pin high or low.

## Pull-up and pull-down resistors

A digital input pin that isn't actively being driven high or low by
anything is **floating** — its read value is undefined noise, not
reliably 0 or 1. A **pull-up resistor** (to the supply voltage) or
**pull-down resistor** (to ground) weakly biases the pin to a known default
state when nothing else is actively driving it, so a button press (which
pulls the pin the other direction) reads reliably instead of floating.
Many microcontrollers have these built in and selectable in software,
avoiding the need for an external resistor.

## PWM: pulse width modulation

A GPIO pin can only be fully on or fully off — it can't natively output
"60% of supply voltage." PWM fakes an effective analog-ish output by
switching the pin on and off rapidly, where the **duty cycle** (percentage
of each cycle spent high) determines the effective average value a
downstream circuit or the human eye perceives.

- **Duty cycle**: e.g. 25% duty cycle = on for 1/4 of each cycle, off for
  3/4 — averages to roughly 25% of full output.
- **Frequency**: how many on/off cycles happen per second. Generated by a
  hardware **timer peripheral** on the microcontroller counting up to a
  threshold and toggling the pin, not by software manually toggling a pin
  in a loop (which would be imprecise and eat CPU time).

## Choosing a PWM frequency matters

Different downstream uses need different PWM frequencies:

- **DC motor speed control**: a few kHz to tens of kHz — too low and the
  motor audibly whines or vibrates at the switching frequency; too high
  wastes switching efficiency in the driver (see the DC motor notes' PWM
  efficiency discussion).
- **Hobby servo position signal**: a specific ~50Hz frequency with pulse
  *width* (not duty cycle percentage) encoding position — this is a
  different use of "PWM" than motor speed control, so a servo signal and a
  motor-speed PWM signal are not generally interchangeable even though both
  are called PWM.
- **LED brightness**: a few hundred Hz to a few kHz is usually enough to
  avoid visible flicker to the human eye.

## Quick reference

| Concept | What it does |
|---|---|
| GPIO digital out | drive a pin high/low |
| GPIO digital in + pull resistor | reliably read a pin that isn't actively driven |
| PWM duty cycle | fraction of each cycle spent high -- effective average level |
| PWM frequency | cycles per second, generated by a hardware timer |
